Six questions, answered properly.

Each one replaces a spreadsheet you would otherwise build badly, and each one shows the assumption that decides the answer.

Nothing you type leaves the browser. That is checkable.

No requests after load

Open your developer tools, watch the network tab, and move every slider on any tool. Nothing goes out. The only requests are the fonts and the animation library, both from a public CDN, both at first paint.

Your numbers live in two places

Your own localStorage, so a return visit picks up where you left off, and the URL after the #, so a link carries the whole scenario to someone else without a server ever seeing it.

Read the model

Every projection is a few dozen lines of plain JavaScript with the formula written out. If a number looks wrong, the arithmetic is right there to check rather than behind an API.
